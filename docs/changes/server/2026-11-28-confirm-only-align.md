# 集对齐改为确证式，文件名编号不再当事实

## 背景

用户的媒体库已不再手工整理文件名，全部是完整磁力原名：

```
[Lilith-Raws] Tensei shitara Slime Datta Ken - 05 [Baha][WEB-DL][1080p][AVC AAC][CHT][MP4].mp4
[Group] Anime Title - OVA [1080p].mp4
```

这类名字里的数字是**发布组编号习惯**，与 Bangumi 的 `sort` 没有必然关系。原规则把它们当作集号事实：

- `00-特别篇.mp4` 直接断言为官方第 0 话（若官方没有 `sort=0`，再退回特别篇）；
- 解析不出编号时，用 `hasSpecialMarker` +「只剩一个特别篇」兜底猜归属；
- 只认 `\d{1,3}`，`One Piece - 1085` 这种四位数集号解析失败。

用户明确指出：`00 特别篇` 不能直接用来判断 `sort` 为 0，「如果我没写 00 怎么办」。

## 改动

### 规则只做确证，不做推断

`alignByRules()` 重写为累积式判定，三条同时满足才给归属：文件名不带特别篇标记、集号可解析、集号在官方正片 `sort` 里唯一存在。

| 情形                                       | 处理                                                     |
| ------------------------------------------ | -------------------------------------------------------- |
| 文件名带「特别篇 / SP / OVA / OAD / 番外」 | 不归规则，记入原因                                       |
| 集号解析不出                               | 不归规则，记入原因                                       |
| 同号文件（两个文件都是 3）                 | 两个都不认，记入原因                                     |
| 集号不在官方正片里                         | 不归规则，记入原因（可能是特别篇、合并集、编号体系不同） |

任一条命中即 `resolved: false`，由模型接手。删除 `hasSpecialMarker` 的兜底归属——它是唯一「用文件名猜内容」的地方。

**保留部分结论**：`resolved: false` 时 `assignments` 仍保留已确证的文件，模型不可用时不会被清空。

### 四位数集号

`parseEpisodeNumber()` 的编号上限从 `\d{1,3}` 提到 `\d{1,4}`（方括号、` - N`、前缀三条规则）。`[1080p]` 因数字后紧跟 `p` 仍不匹配，分辨率不会被误认。

### 提示词

`ALIGN_SYSTEM` 的措辞从「文件名编号就是集号」改为「集号只是提示」：

- 新增：发布组原名里的数字属于发布组习惯，官方无此集号时不要硬套；
- 新增：文件名含特别篇字样时不要仅凭编号判成正片，冲突以官方分类为准；
- 删除：原来「00-特别篇 是第 0 集，属正片」的规定。

长度 1734 → 1661 字符（-4%）。

### 降级

`runPreview()` 调模型改为 `try/catch`：失败时写入 warning 并退回规则已确证的部分，不让整季作废。`missing` 改为按最终采用的对应关系重算，AI 生效时不再沿用规则阶段的结论。

## 取舍

- **不做「永远调模型」**：文件名干净、集号齐全的正片全集仍是 0 调用。这类情况集号与 `sort` 是等值关系，模型给不出更好的结果，只会多花 token 且更不稳定。
- **代价**：带任何特别篇的季、以及缺集导致文件数少于正片数的季，都会各多一次模型请求。相对准确性，这个成本可接受。

## 验证

- `test/server/bangumi-align.test.ts` 重写「规则对齐」一组：正片确证、发布组原名、缺集、00-特别篇 不再断言、集号越界、解析失败、集号重复、特别篇只提示数量。
- 新增四位数集号与 `[1080p]` 不误判的用例。
- `test/server/bangumi-sync.test.ts` 增加「带标记时保留其余可确证文件」的预览用例。
- 实测 23 个真实命名样本：解析 17 个，剩余 6 个分别是 SP01 / OVA / 01-03 / 剧场版 / 日期噪点，均属应交模型或本应无集号。
- 全量 46 文件 453 例通过，`tsc` 干净。
