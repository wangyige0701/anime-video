# 系列类型新增纯爱、节操等 17 个标签

- 日期：2026-11-27
- 模块：shared
- 类型：功能
- 涉及模块：shared、web、server

## 背景

类型枚举此前有 28 项，覆盖档期（TV/剧场版/OVA）、产地、改编来源和主要题材，缺少番剧站点高频使用的口碑类、时长类与喜剧子类标签，也缺少热血、推理、音乐、机战等常见题材。

## 目标与取舍

- 新增用户指定的 4 个标签：`29 纯爱`、`30 节操`、`31 泡面番`、`32 无厘头`。
- 补充 13 个常见题材与受众、情绪标签：`33 热血`、`34 机战`、`35 妖怪`、`36 推理`、`37 恐怖`、`38 历史`、`39 音乐`、`40 偶像`、`41 美食`、`42 青春`、`43 儿童向`、`44 致郁`、`45 催泪`。
- 只在末尾追加，不插入已有类型之间、不重排 id：已有系列的 `types` 存 id，重排会让历史数据指向错误题材；服务端校验用首尾 id 组成合法区间，跳号会放行未定义 id。
- 不做别名收敛：`纯爱` 与既有 `恋爱`、`爱情` 并存，`节操`/`无厘头` 与既有 `搞笑` 并存，由录入方按作品实际标签选择。
- 候选清单里曾出现的「耽美」按要求不加入；战争、生存、群像、赛博朋克、逆后宫、转生、时空穿越、少年向等未纳入本次范围。

## 实现要点

1. 类型列表仍是前端下拉、首页筛选与服务端写入校验的唯一数据源，`DetailTypes.vue`、`IndexFilterBar.vue` 直接遍历 `seriesTypes`，调用方无需改动。
2. 首页标签组 `IndexFilterOptions.vue` 已有「收起一行 + 悬浮浮出完整标签」逻辑，标签增多不会撑高过滤栏，无需改动。
3. 详情页弹层固定宽 350px 且不限高，标签增至 45 项后会向下溢出；改为内容区 `max-height: 240px` 内滚动，并补细滚动条样式，避免深色弹层上出现系统默认滚动条。
4. 测试不再断言列表总数，改为断言末尾 17 项名称与 `getSeriesTypeName()` 对新旧 id 的查询结果，后续追加类型只需更新末尾批次，不会因总数变化误报。

## 行为变化与兼容性

- 已有系列的类型 id 不受影响，历史数据无需迁移。
- 详情页类型下拉与首页筛选自动多出 17 个选项，接口契约与请求参数不变。
- 服务端写入校验区间由 `1–28` 变成 `1–45`。
- 类型下拉在标签超过约 7 行时内部滚动，其余布局不变。
