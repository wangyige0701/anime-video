# 样式修改必须以最少代码实现

- 日期：2026-11-17
- 模块：web
- 类型：文档

## 背景

详情页剧集拖拽的第一版样式为了“好看”，额外增加了新容器 `.episode-head`、手柄的透明过渡与悬停变色、拖拽占位的虚线边框和 `cursor` 变化等。

实际需求只有一个：让手柄可辨认、可抓取，拖拽时有占位反馈。多余样式带来三个成本：

- 类数量增加后，卡片原有的 hover/active 效果容易与新类冲突，需要反复调优先级。
- 主题适配点变多，新增主题时要检查的规则同步增加。
- 代码 review 与后续维护成本上升，收益仅是视觉细节。

## 目标与取舍

确立“样式实现以最少代码为原则”，把判断标准写进 `web/AGENTS.md`：

- 能用现有结构承载的，不新增元素或类；
- 能复用 Element Plus 与主题 token 的，不自定义颜色和动画；
- 只为交互必需（可点击、可拖拽、状态可辨认）写样式，不为装饰写样式。

## 涉及文件

| 文件 | 改动 | 原因 |
| --- | --- | --- |
| `web/AGENTS.md` | 在“样式与主题”章节新增两条约束 | 让样式最小化成为可检查的约定，而不是个人偏好 |
| `web/src/components/detail/DetailSeason.vue` | 删除 `.episode-head` 包裹、手柄过渡与配色、占位虚线、`episode-chosen` | 按新约定把已实现的样式收敛到必要部分 |

## 实现要点

- 手柄直接放进已有的 `.index`，用一条 `display: inline-flex; align-items: center; gap: 5px` 完成对齐，省掉一层容器。
- 手柄只保留 `cursor: grab` 与 `opacity` 悬停反馈；拖拽占位只保留 `opacity: 0.5`。
- 删除只为视觉效果存在的 `chosenClass` 配置，减少一个类与一条规则。

## 行为变化与兼容性

- 交互行为不变：仍为手柄拖拽、卡片点击播放。
- 视觉上占位块不再显示虚线边框，改用半透明显示，与卡片既有样式一致。

## 验证

- `pnpm --filter web type-check` 通过。
- 人工确认详情页卡片 hover/active 效果未被覆盖，拖拽时占位块可见。
