# 收起态时间轴改为白色波形与跟随选区的范围文案

- 日期：2026-11-22
- 模块：web
- 类型：样式
- 涉及模块：web

## 背景

上一版把时间轴做成可缩放、可拖选的面板后，收起态（26px 预览横栏）还有两个问题：

1. **黑色条纹**：收起态柱体用了 `d-6`（选中 `d-9`），选区块是 `d-9` 24% 蒙层。过滤栏底衬是 `sidebar-bg`（浅紫半透明），这些深色叠上去就成了一道道黑条纹，看起来像脏点，与展开面板的浅紫刻度完全不是一套视觉。
2. **范围文案挤在右侧**：收起态的范围文案放在过滤栏右侧，占掉约 90px 轴宽；文案本身跟「选中的是哪一段」没有视觉关联，用户要来回对照才知道选区块对应什么时间。

## 目标与取舍

1. 收起态柱体改为**白色半透明**（选中月份纯白、空档月份更淡），选区改白色薄蒙层 + 白色左右描边，底部只留一条 `rgba(#fff, 0.2)` 基线；不引入深色轨道。
2. 范围文案改为**贴着选区块浮在轴上方 2px**，`pointer-events: none`，拖动时跟随预览范围移动；未筛选时才回退成右侧「全部时间」。
3. 右侧文案与清除按钮改为**固定占位**，避免切换筛选状态时轴宽变化、刻度重新分格。

取舍：

- **不把文案放进选区色块内部**：单月选区只有一个月宽（约 40px），13 个字符的范围文案放不进去，压在柱体上也不好读。
- **不做居中定位**：`left: 50% + translateX(-50%)` 在窄选区靠边时必然溢出容器；改成「默认与选区左端左对齐，选区中心越过 68% 后改为与右端右对齐」，文字始终朝容器内部延伸，不需要测量文字宽度也能保证不溢出。
- **不保留深色轨道**：试过 `rgba(#000, 0.16)` 轨道 + 白柱，对比更强但整条轴发灰、把过滤栏的紫色割裂成两段；去掉轨道、只留淡基线后视觉最轻，柱子仍然立得住。
- **右侧不做动态宽度**：文案长短变化会让轴宽跳动，宁可保留 86px 固定占位。

## 验证

- 单元测试：`pnpm exec vitest run` —— 12 个文件 140 条全绿（`time-axis.test.ts` 34 → 38 条）。
- `vue-tsc --build`、`vite build` 通过。
- 无头 Chrome 真实鼠标事件验证（真实片库）：
    1. 收起态柱体实测 `rgba(255,255,255,0.24/0.62/1)`，选区为白色 0.24 蒙层 + 白色两端描边，截图确认无黑色条纹；
    2. 拖选 `2025-12 ~ 2026-05`，气泡贴在选区块左端上方（`tipLeft` 与 `bandLeft` 对齐），移开指针后气泡随面板收起保留；
    3. 拖到最右端（`2026-05 ~ 2026-10`）时气泡改为右对齐，`tipRight = 0`，未溢出轴；
    4. 单月选区（`2025-08`，宽 35px）气泡宽 40px，仍在轴内；
    5. 切换选中状态前后轴宽均为 982px，刻度不跳动；
    6. 1024px 窄屏下轴宽 406px，气泡 `tipLeft 255 / tipRight 58`，未溢出；
    7. 展开面板与缩放、拖选行为不变。
