# 过滤栏改为内联可拖拽时间轴

- 日期：2026-11-22
- 模块：web
- 类型：功能
- 涉及模块：web

## 背景

时间过滤原来是「触发按钮 + popover 浮层」：点开浮层才能看到刻度，选中后面板自动关闭，调整范围要重新点开一次；浮层挂在 `body` 上、宽度写死 720px，与过滤栏在视觉上是两块互不相关的东西。用户希望像浏览器控制台的性能时间轴那样，在过滤栏这一整段内容里直接放一条可拖拽的轴，悬浮增高显示完整刻度。

同一轮里还暴露出两个相关问题：

- 过滤栏只有控件没有说明，两个分段选择器（标签/状态/时间、上线时间/名称）看不出各自在筛什么；
- 标签选项后续会增多，换行会把过滤栏撑高、挤压列表。

## 目标与取舍

1. 删除 popover，时间轴内联到过滤栏内容区：收起态 20px 高的柱状概览条，悬浮后展开为 84px 的完整轴（年份表头 + 月份数字 + 柱高），整段可选、可拖、可清除。
2. 过滤栏从 45px 提高到 62px，两个分段选择器上方各加一行小字标签（「筛选方式」「排序方式」）。
3. 标签组改为单行裁切 + 悬浮向上展开；只有确实超过一行时才展开，并在右侧加渐隐提示。

取舍：

- 没有引入第三方时间轴库。现有 `useTimeAxisSelection` 已经处理了反向拖动、单月点击、全局 `pointerup` 清理，换成第三方库要重新对齐 `AXIS_TICK_WIDTH` 的像素换算和 `YYYY-MM` 范围语义，收益低于改造成本。
- 展开只做高度变化，不做刻度缩放：收起态与展开态共用同一套滚动容器与刻度宽度，选中范围与滚动位置在展开前后完全一致，避免两套坐标互相换算。
- 不给展开态加「钉住」开关，鼠标移开即收起；需要保留范围时范围本身已经写入 store 与本地存储，刻度条上也有色块标记。

## 实现要点

- **宿主固定高度**：`.axis-wrap` 固定 20px，展开的 `.time-axis` 是它的子元素并向上溢出（`height: 84px`）。如果直接让带 `pointerenter/pointerleave` 的元素自己变高，展开瞬间元素离开指针位置会立刻触发 `pointerleave`，形成展开/收起抖动；宿主不变、面板溢出可以把指针保持在宿主子树内。
- **拖动中不收起**：`dragging` 为 true 时忽略 `pointerleave`；在轴外松手后由 `watch(dragging)` 补一次收起，避免面板常驻。
- **柱高随状态缩放**：`barHeight()` 收起时映射到 1–10px、展开时 2–22px，用同一个数量比例，不引入第二套刻度。
- **选区可见性**：过滤栏底色是浅紫半透明，`opacity: 0.28` 的选区几乎看不出来，提高到 0.42，并保留范围内月份标签变白。
- **单行判断**：收起态 `flex-wrap: wrap` + `max-height: 26px` + `overflow: hidden`，用 `scrollHeight > clientHeight + 1` 判断是否超过一行；展开态是绝对定位，测量无意义，因此 `measure()` 在展开时直接返回。尺寸变化由 `ResizeObserver` 监听容器宽度。
- **展开层不参与布局**：时间轴与标签的展开态都是绝对定位，`IndexFilterBar` 的内容区不再 `overflow: hidden`，否则会把向上浮出的面板裁掉。

## 行为变化与兼容性

- 时间范围的选择方式从「点击打开浮层再拖」变成「悬浮刻度条直接拖」，范围提交时机不变（松手才写 store），过滤规则、存储格式与默认值都没变。
- 过滤栏高度从 45px 变为 62px，列表区域可用高度减少 17px；`views/index.vue` 的 `--filter-bar-height` 是唯一的尺寸来源。
- 标签组不再横向滚动，而是裁切 + 悬浮展开；点击行为与选中规则不变。
- 移除了 `global` 的 `.index-filter-date-popover` 覆盖样式，`IndexFilterDate.vue` 不再依赖 body 级 popper。

## 验证

- `cd web && npx vue-tsc --build` 通过；`npx vite build` 通过。
- 用 20 部跨 2019-01 ~ 2026-01 的临时片库 + 无头 Chrome 实测：
    - 过滤栏高度 62px，两组 `group-label` 文本为「筛选方式」「排序方式」；
    - 鼠标移入刻度条后 `.time-axis` 高度由 20px 变为 84px，移开后回到 20px，无抖动；
    - 在展开轴上从 2023-11 拖到 2024-07，松手后本地存储写入 `dateRange: {from: "2023-11", to: "2024-07"}`，列表从 20 张卡片筛到 3 张，选区色块横跨 9 个月份；
    - 标签行 `scrollHeight 59 / clientHeight 26`，判定为可展开；悬浮后行高 77px 并换行显示全部标签，移开恢复单行。
- 未覆盖：移动端触屏悬浮不可用（触屏没有 hover），收起态仍可直接拖选，属于可接受降级。
