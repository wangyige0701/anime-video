# 时间轴支持拖拽划选、滚轮缩放与范围可视化

- 日期：2026-11-22
- 模块：web
- 类型：功能
- 涉及模块：web

## 背景

上一版把时间轴内联进过滤栏后，交互仍有四个问题：

1. **拖不出选区**：拖拽依赖 `.content` 上的 `pointerdown` + window 监听，没有阻止默认行为，也没有指针捕获；浏览器接管手势后移动与松开事件不稳定，实际表现是「按下去没反应」。
2. **面板透出内容**：展开面板用 `sidebar-bg`（`rgba(..., 0.8)`）+ `backdrop-filter: blur(8px)`，背后的卡片封面会透出来，刻度与选区判读受影响。
3. **每次只能看一屏**：轴按 34px/月渲染并靠原生横向滚动查看，跨度大时无法缩放，拖选也不能越过可视区边缘。
4. **看不出当前位置**：选区只有 `opacity: 0.42` 的主色块，收起态叠在浅紫过滤栏上几乎不可见，也没有任何文字说明当前范围。

## 目标与取舍

1. 拖动改为 `setPointerCapture` + `preventDefault()`，并在指针越过可视区左右边缘时按帧自动平移窗口，可以连续划选超出视野的区间。
2. 展开面板与标签悬浮层统一改成**不透明深色底**（`d-8`），移除 `backdrop-filter`。
3. 时间轴改用**可见窗口**渲染：不再原生横向滚动，只渲染窗口内的月份并等比铺满；滚轮缩放（锚点跟随鼠标）、`Shift + 滚轮` 平移，缩放范围限制在数据范围内。
4. 当前范围同时显示在面板顶部与过滤栏右侧文案；轴上色块在不透明描边之外，收起态改用深色蒙层，保证两种状态都能看到位置。

取舍：

- **不用 CSS `transform: scale` 做缩放**：缩放会同时放大柱体与文字，还会让指针换算叠加矩阵；改窗口数量后刻度宽度由 `宽度 / count` 现算，DOM 里始终只有一屏的月份节点。
- **不保留横向滚动条**：滚动与缩放两套坐标会让「拖动划选」和「拖动滚动」互相打架；平移交给 `Shift + 滚轮`、触控板横向滑动和边缘自动平移，交互语义不冲突。
- **不引入第三方时间轴库**：需要的是窗口模型与指针换算，第三方库（d3-scale / vis-timeline）会带进自己的比例尺与 DOM 结构，仍要重写划选逻辑。
- **缩放上限设为 6 个月**：再放大单月刻度会宽到失去参照，且选单月与拖整年都不需要更细的粒度。

## 实现要点

- **窗口模型**：`AxisWindow { start, count }` 表示可见月份区间。模板只 `slice` 出窗口内的月份，`.month` 用 `flex: 1 1 0` 等比铺满、`.year` 用 `flexGrow: span`，年份与月份天然对齐，不需要像素宽度。
- **缩放锚点**：`zoomAxisWindow(window, factor, anchor, total)` 先按 `factor` 算出新数量，再用 `(anchor - start) / count` 保持锚点的相对位置不变，所以滚轮缩放时指针下的月份不会跳走。
- **指针捕获**：`pointerdown` 里 `event.preventDefault()` 阻止文本选择与原生拖拽，再 `setPointerCapture(pointerId)`；移动与松开仍统一挂 window，拖出浏览器窗口也不会漏掉 `pointerup`。
- **边缘自动平移**：`panDirection()` 判断指针是否越过可视区左右边界，`requestAnimationFrame` 每 40ms 平移窗口的 5%（至少 1 个月）；到数据两端时 `onAutoPan` 返回 `false`，动画帧停止，不空转。
- **取消手势**：`pointercancel` 只清理状态、不提交范围，避免把系统取消的手势当成一次选择。
- **范围可视化**：色块用百分比定位（`rangeToBand`），范围超出窗口时裁剪到边缘；填充用 `primary` 34% + 不透明 `l-8` 左右描边，选中月份的柱体与文字提到 `l-9`。收起态底衬是浅色过滤栏，改用 `d-9` 24% 蒙层 + `d-9` 描边。
- **常驻文案**：`IndexFilterDate` 右侧显示 `formatAxisRange()` 结果（未筛选为「全部时间」），面板顶部同时显示选中范围与「当前显示窗口」，缩放后出现「显示全部」按钮。
- **初始窗口**：`initialAxisWindow()` 按「每格 34px」折算数量并贴住最右侧（保持改造前的浏览习惯）；已保存范围时把范围居中，刷新后能直接看到筛选位置。

## 行为变化与兼容性

- 时间轴不再有横向滚动条：查看更早月份需要滚轮缩小或 `Shift + 滚轮` 平移，面板顶部会提示这两个操作。
- 过滤栏时间行的行高由 20px 提高到 26px（过滤栏总高仍是 62px），拖动更容易命中。
- 存储格式、`YYYY-MM` 范围语义、过滤规则、默认排序都未变；旧的范围数据可直接复用。
- 悬停在时间轴上滚动会缩放而不是滚动页面，与 DevTools 性能面板一致；面板收起后同样的选择仍然可见。
- 标签悬浮层与新面板同色，切换「标签/时间」不再出现一透一实的观感差异。

## 验证

- `cd web && npx vue-tsc --build` 通过；`npx vite build` 通过；`npx vitest run test/web/time-axis.test.ts` 34 条通过。
- 用真实片库（40 个月刻度）+ 无头 Chrome 派发真实鼠标事件实测：
    - 悬浮后 `.time-axis` 高度 26px → 112px，年份表头 3 段、可见月份 23 个，面板顶部为「拖动选择时间范围 / 2024-12 ~ 2026-10」；
    - 在轴中部按住拖到 12 个月宽度，松手后过滤栏文案变为 `2025-09 ~ 2025-11`，色块宽 105px、3 个月刻度高亮，列表按新范围过滤；
    - 同一位置滚轮向上 3 档：可见月份 23 → 11，窗口从 `2024-12 ~ 2026-10` 收窄到 `2025-04 ~ 2026-02`，锚点附近月份位置不变；
    - `Shift + 滚轮`：窗口平移为 `2025-05 ~ 2026-03`；
    - 缩放到 11 个月后按住拖到面板右外侧并停留 0.9s：首个可见月份由 `2025-05` 推进到 `2025-12`，说明边缘自动平移生效；
    - 点击「显示全部」：可见月份回到 40（全量），月份文字在 22px/格时正常显示、空档月份保留 3px 短刻度；
    - 截图确认面板为不透明深色底，背后卡片封面不再透出；收起横栏能看到蒙层选区、深色柱体与右侧范围文案。
- 已知现象：当筛选结果为空、列表高度骤降时过滤栏会随滚动容器上移，指针已经离开轴，面板随之收起；范围文案仍保留，属于可接受行为。
