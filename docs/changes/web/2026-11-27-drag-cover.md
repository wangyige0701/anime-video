# 拖拽浮层翻面后保留封面图

- 日期：2026-11-27
- 模块：web
- 类型：修复
- 涉及模块：web

## 背景

拿起卡片时浮层会翻面（`rotateY(180deg)`），翻过去看到的是背面。背面只有一条深色渐变加标题，于是拖拽中的卡片看起来是一张**黑底卡片**——预览里最有辨识度的海报反而消失了，用户只能靠一行标题确认自己在拖哪一部。

## 涉及文件

| 文件                                     | 改动                                                    |
| ---------------------------------------- | ------------------------------------------------------- |
| `web/src/components/index/IndexList.vue` | 背面沿用海报做背景、新增 `has-cover` 与遮罩、无封面占位 |
| `docs/modules/web/series-merge.md`       | 状态机补充「两个面都显示封面」的结论与约束              |

## 实现要点

1. **背面复用同一个 URL**：`dragCoverStyle` 把 `dragState.imageUrl` 写成 `background-image`，`background-size: cover` 居中裁切，与正面 `<img>` 的 `object-fit: cover` 视觉一致。
2. **底部渐变遮罩**：`.has-cover .back::before` 从下往上 `rgb(0 0 0 / 78%) → 6%`，标题放在遮罩之上（`position: relative; z-index: 1`）。亮色海报上的白字不加遮罩会糊成一片。
3. **标题改为底部对齐**：原来背面是 `align-items: center`（整块只有文字），现在有封面，标题压在底部更符合海报卡片的读法，也不会盖住画面主体。
4. **两面都要底色兜底**：底色从 `.back` 移到 `.face`。之前只有背面有渐变，正面靠 `<img>` 撑；系列没有封面时正面是透明的，浮层会变成一块看不见的玻璃。现在正面无封面时显示居中标题占位。
5. **`has-cover` 类挂在卡片根节点**：遮罩只在有封面时叠加，没有封面时保持原来的纯色 + 标题外观。

## 行为变化与兼容性

- 有封面的系列：拖拽浮层正反面都是海报，背面多出底部标题与暗角。
- 没有封面的系列：两面都是深色底 + 居中标题，与改动前的背面完全一致。
- 翻转动画、飞入/飞回、命中检测、叠层与合并逻辑均未改动。

## 验证

- CDP 实测（1440×900）：拖起「学生会也有洞！」后 `.series-drag-card` 带 `flipped has-cover`，背面 `background-image` 为海报 URL、`background-size: cover`、`align-items: flex-end`，遮罩渐变生效。
- 截图核对：浮层显示海报封面 + 底部标题，不再是黑底卡片。
- 回归 `merge-ui-check`：自动滚动 `0 → 854`、悬停出现虚线框与滑入层、合并成功（`badge=1`、1 层叠图、源卡片消失）、成员面板脱离后成员恢复、服务端残留合并关系 0。
