# 底部过滤栏层级低于卡片导致被遮挡

- 日期：2026-11-27
- 模块：web
- 类型：修复
- 涉及模块：web

## 背景

首页滚到底部时，最后一行的卡片会压在底部过滤栏上面，把「过滤方式 / 排序方式」的控件盖掉一部分，标签组与时间轴也一起被遮。

## 原因

过滤栏 `.filter` 只给了 `z-index: 2`，而卡片内部的层级是 `.link` 10、`.drop-target::after` 30、`.merge-badge` 40。这些 `z-index` 挂在 `.series-card` 的子元素上，而 `.series-card` 是 `position: relative` 但没有 `z-index`——它**不会**建立层叠上下文，于是这些子元素直接与外层的 `.filter` 比较，10 > 2 就被盖住了。

## 涉及文件

| 文件                      | 改动                   |
| ------------------------- | ---------------------- |
| `web/src/views/index.vue` | `.filter` 层级 2 → 100 |

## 实现要点

1. **抬高过滤栏而不是压低卡片**：卡片内的层级是为叠层（0）、落点框（30）、角标（40）服务的，压低会破坏这些元素的相对关系；过滤栏只是一个底部操作区，给它一个明确高于 40 的值最省事。
2. **不能高过拖拽浮层与弹层**：浮层挂在 `body` 上是 2600，成员面板走 Element Plus 弹层（2000+），都必须在过滤栏之上，所以取 100 而不是几千。
3. **注释写清为什么是 100**：把「卡片内 10/30/40 会逃逸到外层」这一层叠上下文的细节留在代码旁边，避免后来的人看到 100 又把它改回 2。

## 行为变化与兼容性

- 过滤栏重新盖住滚到它下面的卡片；时间轴与标签向上展开时同样在卡片之上。
- 拖拽浮层、成员面板、消息提示的层级不受影响。
- 过滤栏的半透明底衬、高度、`sticky` 行为不变，列表布局不受影响。

## 验证

- CDP 实测：滚到底部（`scrollTop = 99999`）后，过滤栏中心点与内部控件位置 `elementFromPoint` 均命中 `.filter` 内部元素，`getComputedStyle(.filter).zIndex === '100'`。
- 截图核对：过滤栏完整可见，第三行卡片被正常压在下面。
- 回归 `merge-ui-check`：拖拽、合并、脱离、自动滚动全部正常。
