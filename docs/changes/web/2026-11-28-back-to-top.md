# 首页重复点击不再回跳，并新增回到顶部按钮

- 日期：2026-11-28
- 模块：web
- 类型：修复 / 功能

## 一、已在本页再点侧边栏「首页」会被拉回旧位置

### 现象

从详情页后退回首页（已恢复到离开时的位置），继续往下滚一段，再点左侧浮栏的「首页」，页面跳回刚才那个旧位置。

### 原因

侧边栏用 `<router-link :to="{ name: 'Index' }">`，已经在首页时点它是**重复导航**。vue-router 会把它判为 `duplicated` 失败，但仍然会调用 `triggerAfterEach(to, from, failure)`：

```js
// dist/vue-router.esm-browser.js
triggerAfterEach(toLocation, from, failure);
```

`scrollGuard` 的 `afterEach` 没有检查这个 `failure`，于是照常走了「恢复该历史序号的位置」这条分支，把位置设回上次记录的值。

### 修复

`afterEach` 收到 `failure` 时直接返回。失败或被拦下的导航不会改动历史记录，也就没有位置需要恢复；这条同时覆盖守卫里 `return false` 与被打断的导航。

行为：在首页滚动后点「首页」，位置保持不动（用户要求「不再触发滚动」）。如果希望它回到顶部，把这一支改成 `memory.reset()` 即可。

## 二、回到顶部按钮

新增 `components/common/BackToTop.vue`，由 `App.vue` 挂在滚动容器旁：

- 只负责显示与触发，滚动位置与平滑滚动都由 `App.vue` 处理（容器是 `el-scrollbar` 的 wrap，不是 window）；
- 滚动超过 400px 才出现，回到顶部后自动隐藏；
- `bottom: 88px`：首页过滤栏高 62px、距底 5px，留 21px 间距，任何宽度下都不压住底部操作栏；
- 层级 900：高于过滤栏（100）与卡片内容，低于播放器（1000）、全局遮罩（2000）与拖拽浮层（2600）。

## 验证

夹具 200 条、1440×900：

```
初始        top 0    按钮 false
滚到 1200   top 1200 按钮 true   按钮底 812 / 过滤栏顶 833 → 不重叠
点回顶      top 0    按钮 false
点首页      top 1200 保持不动（修前会回跳）
详情页      top 0
回退        top 800  恢复到位
```

补充：350px 不显示、420px 显示；900×700 窄屏按钮底 612 / 过滤栏顶 633，仍不重叠；日落橙主题下按钮底色 `rgb(175,95,31)`、图标 `rgb(243,225,211)`，对比充足。

`type-check`、`build`、`check-vue-tags`、`vitest run`（44 文件 / 430 例）通过。

## 影响面

- 重复导航不再改动滚动位置；正常前进/后退、replace 的行为不变。
- 按钮是全局的，详情页、收藏、历史等页面滚动超过阈值同样会出现，位置统一在右下角。
