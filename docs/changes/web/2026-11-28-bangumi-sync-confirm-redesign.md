# Bangumi 同步确认面板重做：语义状态色与信息层级

- 日期：2026-11-28
- 模块：web
- 类型：优化
- 涉及模块：web

## 现象

确认变更这一步的可用性有几个硬伤：

- 一行末尾的「与当前一致」是个几乎和背景同色的浅块，扫一眼分不出哪些会被替换、哪些不会。
- 正片季那一行是「正片 → 白圣女与黑牧师」，没有字段名，看不出箭头两侧分别是什么。
- 集标题只显示新标题，本地原标题完全看不见，也没有「文件」以外的说明。
- `按预览顺序重排 12 集` 与「顺序一致」标签贴在一起，没有间距；标签用主色描边，在暖色主题上辨识度很差。
- 整列 `inset 2px` 左侧色条逐行重复，一屏十几条竖线，视觉疲劳明显。
- 旧值用删除线，一整行被横线穿过，中文长句几乎无法阅读。

## 结构与文案

系列信息、季、集三层都用同一套「一行」结构：勾选框、字段名、值、行尾状态。

| 层       | 字段名                                   | 值                                  | 状态                                     |
| -------- | ---------------------------------------- | ----------------------------------- | ---------------------------------------- |
| 系列字段 | 标题 / 剧情简介 / 上线时间 / 状态 / 类型 | 无变化：单值；有变化：`旧值 → 新值` | 保持当前值（绿）/ 将替换（红）           |
| 季       | 季标题、按预览顺序重排 N 集              | 同上                                | 同上，重排另有「顺序不变 / 顺序将调整」  |
| 集       | 序号 + 标题                              | 标题；有变化时多一行「原集标题」    | 无标签，变化项标题提亮、无变化项整行压暗 |

- **状态用语义色 + 文字**：绿 `#8fd67a`（与设置页「已配置」同色值）表示保持，红 `#ff8f8f` 表示替换。用低饱和版本，深色面板上不刺眼；圆点 + 文字比胶囊更轻，不会在列表里重复成一片色块。
- **旧值只压暗、不划删除线**，方向交给箭头与新值的提亮。
- **不给自己加左侧色条**，变化行只用浅底色 `d-3` 区分。
- 分组头给出汇总：「将更新 2 项，其余保持当前值」/「将更新 6 处」/「全部与当前一致」，用户不必逐行数。
- 页脚把「应用 8 项」拆开：`将写入 8 项：系列字段 2 · 集标题 5 · 重排 1 季`，能核对勾中的是哪几类。

## 步骤条换成图标

顶部两步提示原来用 `el-steps` 的 `simple` 模式，它的连接箭头是两根 1px 斜线（`::before`/`::after` 画的），
和图标体系不搭、缩放后发毛。改成自绘步骤条：序号圈 + `Right` 图标箭头，已完成步骤显示 `Check`，
颜色全部走主题梯度；`assets/elements/steps.scss`（当时为这套 `el-steps` 写的覆盖）随之删除，
`elements.scss` 与 `docs/modules/web/element-theme.md` 的清单同步移除 `steps`。

## 主题适配

面板所有颜色仍取自 `token.$theme` 的梯度（`d-2`/`d-3`/`d-4`、`l-4`…`l-9`），只有两个语义色是固定值——一致性状态需要跨主题保持同一含义，跟着主题走反而会让「绿=保持」在暖色主题上失真。每个主题都实测过对比度（见验证）。

## 验证

无头 Chrome + CDP `Fetch` 拦截 `/data/*`，用固定夹具（系列 1 个、季 1 个、6 集，其中 1 集标题与本地一致）驱动面板，逐个主题截图：

- 五个主题（星夜紫 / 深海蓝 / 薄荷青 / 樱花粉 / 日落橙）下状态色、次要比注、无变化行都清晰，暖色主题下也没出现「绿字糊在棕色底上」。
- 夹具里同时包含「一致」与「将替换」两种行，确认：一致性行只有一份值、没有箭头；替换行旧值压暗、新值提亮；集的「原集标题」只在变化时出现。
- 复跑脚本保留在 `.cache/sync-confirm-check.mjs`（`.cache` 已被忽略）。

`pnpm --filter web type-check`、`pnpm --filter web build`、`node scripts/check-vue-tags.mjs`、`pnpm exec vitest run`（40 文件 / 398 用例）通过。
