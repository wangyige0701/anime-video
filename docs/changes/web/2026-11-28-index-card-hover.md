# 主页卡片：合并角标可辨识化，悬停去掉白色光晕

## 问题

1. **合并角标只有一个裸数字**，用户看不出它代表什么，也没有任何说明性交互（原来只挂了一个原生 `title`，延迟长、样式不可控）。
2. **悬停是三层白色光晕**。`0 0 4px primary` + `0 0 8px l-5` + `0 0 12px l-9`，`l-9` 是接近白的浅色，在暗色主题下整张海报被一圈白光糊住，和页面底色也打架。
3. 标题悬停还叠了 `drop-shadow(0 0 6px l-9)`，同样是白光。

## 改动

### 角标

- **图标 + 数字**：`Files` 图标表达「多份」，数字表示成员数量。
- **悬停原地展开**：`max-width` 过渡，数字淡出、文字「已合并 N 个系列」淡入，角标从 ~36px 长到 ~116px，贴着右缘向左扩展，不出卡片。
- **底色提亮一档**：`color-mix(in srgb, var(--theme) 86%, #fff)`。纯 `primary` 在深蓝、深绿主题下与海报同族，会糊进图里。
- **三层边界**：深色外描边 `1.5px`、投影、内侧白高光。海报亮度不可控，靠这三层保证任何图上都能辨认。
- **窄屏兜底**：`max-width: calc(100% - 12px)`，文字 `ellipsis`。

### 悬停

```scss
box-shadow:
	0 0 0 1px map.get(token.$theme, 'l-6'),
	0 16px 32px -12px rgba(0, 0, 0, 0.75);
```

描边取 `l-6`（主题提亮两档）而不是 `primary`：后者在深蓝、深绿主题下与页面底色几乎同色，半透明后等于没有边界。

配套：主图 `translateY(-2px)`、内图 `scale(1.06)`、标题 `l-8 → l-9`、叠层再退开 3px（暗示下面还压着卡片）。**全程不使用白色发光。** 拖拽落点原来的 `0 0 18px 2px l-5` 一并换成中性深投影。

## 踩到的坑

第一版把 `el-tooltip` 套在 `el-popover` 的 `#reference` 里，**成员面板打不开了**（实测 `.el-popover` 存在但 `display: none`）——tooltip 接管了 reference 的 click。

第二版改成 `::after` 自绘浮层，但角标贴着卡片右缘，浮层向左会溢出卡片、压到相邻项。

最终选择让角标自己展开：不引入第二个弹层，宽度受 `max-width` 约束，也不会遮挡别的东西。
