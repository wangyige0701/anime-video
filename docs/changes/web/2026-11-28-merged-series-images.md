# 合并系列时一并展示成员的海报

- 日期：2026-11-28
- 模块：web
- 类型：修复

## 现象

主系列合并另一个系列后，详情页左侧只轮播主系列自己的图，成员系列的海报没有出现。`DetailImage` 本身支持多图轮播与预览，是数据没送进去。

## 原因

`mergeSeries()` 只处理 `mergedIds`，不碰 `images`；详情页也直接把 `series.value.images` 传给 `DetailImage`。季已经做了成员拼接（`memberGroups`），图片没有跟着走同一条链路。

## 修复

`views/[seriesId]/[name].vue`：

- `loadMembers()` 顺带收集成员的 `images`，存进 `MemberGroup`（该对象原本只带 `id / title / seasons`）；
- 新增 `displayImages`：主系列图片在前，成员图片按 `mergedIds` 顺序追加，用 `mergeUnique` 去重保序；
- 模板改为 `<DetailImage :images="displayImages" />`。

**只做展示层聚合，不写回 `images` 字段。** 系列图片对外是绝对路径（服务端 `readers.images` 按各系列目录拼好），跨系列拼接不需要换基准目录；写回则会分不清哪张图来自哪个成员，脱离合并后还留在主系列里。

## 验证

用固定夹具拦截 `/data/*`：

| 场景                    | 图片数        | 预览路径                                     |
| ----------------------- | ------------- | -------------------------------------------- |
| 主系列 2 张 + 成员 1 张 | 3（`dots` 3） | `main/1.jpg` → `main/2.jpg` → `member/3.jpg` |
| 未合并（对照）          | 2（`dots` 2） | `solo/a.jpg` → `solo/b.jpg`                  |

真实数据：`碧蓝航线：微速前进`（1 张）合并 `碧蓝航线：微速前行！`（1 张），详情页 `dots` 由 1 变 2，季仍是 2 组，截图确认海报与轮播点正常。

`type-check`、`vitest run`（44 文件 / 430 例）通过。没有改服务端与数据文件，已有的合并关系无需迁移。

## 影响面

- 只影响详情页图片区；首页卡片仍用主系列首图（叠层另有成员首图）。
- 成员系列多图时轮播点会变多，与「单系列多图」的表现一致。
