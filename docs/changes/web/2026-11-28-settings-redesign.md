# 设置页重做：分组结构、面板视觉与偏好接入

- 日期：2026-11-28
- 模块：web
- 类型：优化
- 涉及模块：web

## 背景

上一版设置页能改配置，但视觉与结构都站不住：

- 页面标题下压着一整行说明文字，去掉也不影响信息传达。
- 左侧只有「外部服务」一组两项，右侧一张表单卡片，面板里除了字段没有别的信息。
- 输入框是主色混 10% 白的浅紫块，占位色 `l-8` 接近正文白，分不清框里是实值还是提示。
- 数字框占满整行、文字居中、右侧两片白色加减按钮。
- 「高级」是一条通栏横线，没有 hover 反馈、箭头不转，看不出能点。
- 密钥行的「替换」是 text 按钮，hover 底色是 `--el-fill-color-light`（近白），鼠标一放上去就是一块白板。

## 结构与数据

分组改为两层，本机偏好与外部服务分开：

| 分组     | 路由                  | 内容                                 |
| -------- | --------------------- | ------------------------------------ |
| 通用     | `/setting/appearance` | 外观：主题色板                       |
|          | `/setting/player`     | 播放器：默认音量、自动连播、字幕开关 |
| 外部服务 | `/setting/ai`         | AI 接口                              |
|          | `/setting/bangumi`    | Bangumi                              |

进入 `/setting` 重定向到外观。删除页面副标题，标题、面板标题、说明、摘要、字段标签统一从面板内边距起排；面板头部不再放图标块——图标会把标题右移，与下面的字段列形成两条竖线。

**面板摘要**（`SettingSection` 的 `meta`）显示已保存的生效值，与表单里正在编辑的内容分开：AI 是接口地址 / 模型 / 超时，Bangumi 是接口地址 / User-Agent / 超时，外观是当前主题，播放器是音量 / 自动连播 / 字幕。

**外观与播放器是真实接入，不是占位**：

- 主题读 `config/theme.ts` 新增的 `THEME_OPTIONS`（与 `themes.scss` 的 `$themes` 一一对应），点击调 `themeStore.setTheme`。
- 主题首次持久化：`utils/themeStorage.ts` 用同步 `localStorage`（异步存储会让首帧闪默认配色），读取时用 `parseTheme` 校验枚举值。`stores/theme.ts` 顺手修正了清 class 的 bug——原来 `for..in` 拿到的是字符串枚举的键 `Xingyezi`，与 class 名 `xingyezi` 不同，旧主题 class 从来没被清掉过。
- 播放器偏好直接双向绑定 `stores/player.ts` 的 `setVolume` / `setIsAutoPlay` / `setIsSubtitleTrack`，改动即时生效并写入本机存储，不另建状态。

## 顺带修正

- AI 地址说明不再写「含 /v1」：DeepSeek 等服务的 OpenAI 兼容地址就是根地址，`/v1` 只是部分服务的写法。服务端 404 文案同步从「请确认地址是否包含版本段（如 /v1）」改为「请按服务商文档核对路径」。
- `vitest.config.ts` 增加 `@/` 别名（正则限定前缀，避免误伤 `@element-plus/*` 包名），使前端模块的纯函数可以被直接测试。

## 已知限制

- `el-switch` 开启态用既有 `switch-on-bg`（主色黑化），在面板上对比略弱；那是播放器 HUD 共用的变量，本次不动。
- `ElMessage` 仍是浅色底，与深色主题不完全协调，属全局提示组件，未在此次范围内。
