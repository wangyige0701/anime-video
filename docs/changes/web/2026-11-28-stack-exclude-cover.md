# 叠层排除封面来源系列

## 现象

两个系列合并后把成员图片拖到首位，卡片本体显示成员的海报，叠层里**仍然**压着这个成员的首图——同一张图在卡片和背后各出现一次，而主系列的海报没有出现。

## 原因

`stackImages` 直接按 `mergedIds` 顺序取每个成员的首图，从未判断「封面是谁的」。封面切到成员之后，那个成员既占了卡片本体，又占了一层叠层。

## 改动

`getMergeCovers()` 增加 `stack` 字段（`web/src/utils/seriesMerge.ts`）：

- 先算出每个系列（主系列 + 成员）在最终顺序里的首图；
- 判断封面归属：`ordered[0]` 落在哪个系列的图片集合里，就是谁；没有图片时归主系列；
- `stack` = 除封面来源外每个系列的首图，顺序为「主系列在前，其余按 `mergedIds`」，最多仍由调用方取 3 层。

`SeriesCard.vue` 的叠层改用 `mergeCovers.stack`，其余（封面、成员面板缩略图）不变。

## 结果

- 两个系列合并、封面来自子系列：卡片 = 子系列图，叠层 1 层 = 主系列首图；
- 封面来自主系列：行为与之前一致，叠层是各成员首图；
- 三个及以上系列：封面来源让位，其余系列仍按合并顺序铺开，主系列补到最近一层。

## 验证

- `test/web/series-merge.test.ts`：31 例通过，新增/改写覆盖「封面来自成员时叠层排除该成员」「两系列合并叠层只剩主系列一张」「封面来自主系列时叠层不变」「无合并时叠层为空」。
- `pnpm --filter web type-check`、`check-vue-tags`、`check-undefined` 通过；全量 `pnpm exec vitest run` 49 文件 514 例通过。
- 手工验证：两个系列合并 → 详情页把子系列图片拖到第一 → 返回首页，卡片应显示该图，背后只叠一层主系列海报（不再出现重复的那张）。
