# 主题色压暗：除星夜紫外统一到暗色亮度档

- 日期：2026-11-28
- 模块：web
- 类型：优化
- 涉及模块：web

## 现象

外观分组里除星夜紫外的四个主题整页偏亮：深海蓝、薄荷青、樱花粉、日落橙切过去后背景是一块高饱和的亮色，和「暗色主题」定位不符。

## 根因

页面背景不是纯色，而是基色的两次混合（`themes.scss`）：

```scss
--theme-bg:
	radial-gradient(circle at top, color.mix(#000, $color, 18%), transparent 55%),
	linear-gradient(180deg, color.mix(#000, $color, 5%), color.mix(#000, $color, 50%));
```

顶部只掺 5% 黑，基色几乎原样铺满首屏；`--sidebar-bg` 更是 `mix(#fff, $color, 10%)` 再给 0.8 透明度，直接向白色方向偏。所以基色亮度基本等于整页亮度。五个基色的 WCAG 相对亮度：

| 主题   | 原色      | 相对亮度 Y | 与白字对比度 |
| ------ | --------- | ---------- | ------------ |
| 星夜紫 | `#7b61ff` | 0.200      | 4.20:1       |
| 深海蓝 | `#4a90e2` | 0.269      | 3.29:1       |
| 薄荷青 | `#21c7ab` | 0.441      | 2.14:1       |
| 樱花粉 | `#ff6fa7` | 0.354      | 2.60:1       |
| 日落橙 | `#ff9e4d` | 0.462      | 2.05:1       |

薄荷青与日落橙的亮度是星夜紫的 2.2–2.3 倍，切过去必然发光。

## 调整

保持色相不动，降明度（必要时降饱和），把四个基色压到星夜紫同一亮度档：

| 主题   | 原色 → 新色           | 新 Y  | 新对比度 |
| ------ | --------------------- | ----- | -------- |
| 星夜紫 | `#7b61ff`（不动）     | 0.200 | 4.20:1   |
| 深海蓝 | `#4a90e2` → `#2f7ac9` | 0.187 | 4.42:1   |
| 薄荷青 | `#21c7ab` → `#1a8f7d` | 0.213 | 3.99:1   |
| 樱花粉 | `#ff6fa7` → `#cc4a80` | 0.193 | 4.32:1   |
| 日落橙 | `#ff9e4d` → `#c26a22` | 0.219 | 3.90:1   |

没有往基色里兑灰：兑灰会让色相发脏，这里是把 HSL 明度压下来，青、粉、橙仍然能一眼认出是什么色。

## 实测

无头 Chrome 打开 `/setting/appearance`，逐个挂上主题 class 截图，用 canvas 统计整页平均色与平均亮度（1280×800）：

| 主题   | 调整前平均亮度 | 调整后平均亮度 | 调整后平均色 |
| ------ | -------------- | -------------- | ------------ |
| 星夜紫 | 0.092          | 0.091          | `#5544af`    |
| 深海蓝 | 0.122          | 0.086          | `#22558a`    |
| 薄荷青 | 0.193          | 0.097          | `#146357`    |
| 樱花粉 | 0.157          | 0.088          | `#8c3459`    |
| 日落橙 | 0.203          | 0.100          | `#854a19`    |

调整后五者的整页亮度落在 0.086–0.100，彼此相差不到 ±10%，都在星夜紫的档位上。

交互也走了一遍真实路径：点击「日落橙」色板 → 根节点 class 变 `riluocheng`、`localStorage.theme` 落盘、`--theme` 为 `#c26a22`；刷新后仍是 `riluocheng`（无色块闪烁、无回退默认色）。

## 防回归

`test/web/theme-storage.test.ts` 新增两个用例：

- 解析 `themes.scss` 的 `$themes`，与 `THEME_OPTIONS` 逐一比对——两处色值不一致会直接失败（原来只靠注释约定）。
- 除星夜紫外，每个基色的相对亮度不得超过星夜紫的 1.15 倍，防止后续加主题时又塞进亮色。
