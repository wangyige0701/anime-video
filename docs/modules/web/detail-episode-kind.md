# 详情页集类型标注与切换

适用文件：`web/src/components/detail/DetailSeason.vue`、`web/src/data/episode.ts`、`web/src/api/episode.ts`、`shared/episode-kind.ts`。

## 1. 职责边界

- 负责：把某一集标成「正片」或「特别篇」，并在详情页剧集卡片上显示出来。
- 不负责：排序、分组、播放。集类型只影响标注与 Bangumi 同步时的分类，**不改变集在季内的位置**，也不会把特别篇挪到列表末尾。
- 数据来源有两个：Bangumi 同步写入（官方 `type` 映射）、用户在详情页手动切换，后者优先，直到下一次勾选该集同步才可能被覆盖。

## 2. 数据结构

| 层     | 位置                                     | 说明                                                                              |
| ------ | ---------------------------------------- | --------------------------------------------------------------------------------- |
| 类型   | `shared/episode-kind.ts`                 | `EpisodeKind = 'main' \| 'special'`，前后端共用；`isEpisodeKind()` 用于运行时兜底 |
| 持久化 | `.video.json` 的 `episodes[].kind`       | 缺省视为 `main`，旧数据无需迁移                                                   |
| 服务端 | `Episode.kind`（`ServerToPromise` 字段） | `PUT /data/episode/:id/kind`，写入后 `waitDataSave()`                             |
| 数据层 | `Episode.kind`（`ref<EpisodeKind>`）     | 乐观更新 + 失败回滚，状态位 `kindRef`                                             |
| 组件   | `episode.kind` / `episode.kindRef`       | 决定标签样式与是否禁点                                                            |

## 3. 交互

集卡片「第 N 集」一行右侧的胶囊标签：

| 当前   | 显示                                      | 点击后     |
| ------ | ----------------------------------------- | ---------- |
| 正片   | 默认隐藏，悬停卡片显示 `+ 特别篇`（虚线） | 标为特别篇 |
| 特别篇 | 常驻 `特别篇`（实线亮边）                 | 恢复正片   |

- 标签点击必须 `@click.stop`：卡片整体点击是播放。
- 请求期间 `pointer-events: none` + 降透明度，避免连点。
- 正片态默认隐藏是刻意的：每张卡片都挂一个常驻按钮会让列表显得很吵，只有悬停或当前播放的卡片才露出提示。
- **必须有 `cursor: pointer` 与自身的 `:hover` 反馈**：只靠原生 `title` 提示时，鼠标移上去既不变指针、也不变色，用户以为这里不可点。悬停正片态把虚线换成实边、`l-4` 边框、`d-2` 底、`l-9` 字；悬停特别篇态反而压暗到 `l-7`，与「点了会改回去」的语义一致。

## 4. 样式取舍

特别篇标签最初用「主题色文字 + 浅底」，在暗色主题下与底色同族，10px 的字几乎读不出来（CDP 放大 4 倍确认过）。最终方案：

- 文字用 `l-9`（最亮一级），底色 `d-2`（比卡片默认的 `d-4`、悬停的 `d-3` 更亮），实线边框 `l-3`；
- 正片态用虚线边框 + `l-7` 灰字，靠「实线 / 虚线」区分状态，而不是靠颜色；
- 字号 `0.625rem`、内边距 `0 5px`、`line-height: 1.6`，胶囊只比文字高一点，避免在集号行里占出按钮的分量。

## 5. 同步时的写入规则

`applyChangeSet` 只在 `episodes[].kind` 有值时写类型：

- 前端只为用户勾选的集提交，且只对**已匹配到官方剧集**的集带 `kind`（`unmatched` 只写标题）；
- 未勾选的集不提交 → 用户手改的类型不会被批量同步覆盖；
- 勾选了某集 → 标题与类型一起写，因为官方分类与标题来自同一条官方剧集记录。

## 6. 验证方式

1. `pnpm exec vitest run`（DTO 键集合、apply 写入、前端 apply 入参）。
2. `pnpm --filter web type-check`。
3. 详情页手动验证：悬停正片卡片出现 `+ 特别篇` → 点击后变常驻 `特别篇` → 刷新页面仍保持；再点一次恢复正片。
4. 回归：点击卡片仍能播放；拖拽排序不受类型影响；同步预览勾选集标题后，集类型与标题一起更新。
