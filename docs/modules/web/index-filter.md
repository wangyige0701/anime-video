# 首页过滤与排序

## 1. 职责边界

本模块负责首页（`views/index.vue`）中**已加载列表的本地筛选与排序**，不负责：

- 请求服务端分页或过滤：接口只返回全量系列，分页、过滤、排序、分组全在前端完成。
- 系列详情装配、播放、收藏等其它首页能力。
- 修改服务端数据：过滤条件只影响展示，不写回 `.video.json`。

## 2. 分层与文件

| 层次     | 文件                                                                 | 职责                                                                                                |
| -------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 纯规则   | `utils/seriesQuery.ts`                                               | 关键词匹配、标签/状态/时间过滤、排序、分页、按年月分组                                              |
| 纯计算   | `utils/timeAxis.ts`                                                  | 连续月份刻度、年份归并、可见窗口缩放/平移、坐标换算、范围色块、文案格式化与气泡对齐                 |
| 状态     | `stores/indexFilter.ts`                                              | 过滤方式、选中标签、选中状态、时间范围、排序方式，并持久化                                          |
| 数据入口 | `data/series.ts`                                                     | `querySeries()` / `getAllSeries()` / `getSeriesByPage()`                                            |
| 容器     | `components/index/IndexFilterBar.vue`                                | 底部过滤栏：方式切换 + 内容区 + 排序切换                                                            |
| 子组件   | `IndexFilterOptions.vue`、`IndexFilterDate.vue`、`IndexTimeAxis.vue` | 多选标签组（单行 + 悬浮展开）、时间过滤容器（内联刻度条 + 固定操作位 + 文字清除按钮）、可缩放刻度轴 |
| 交互     | `components/index/useTimeAxisSelection.ts`                           | 时间轴指针划选、指针捕获、边缘自动平移与全局监听清理                                                |
| 列表     | `components/index/IndexList.vue`                                     | 渲染片段（卡片 / 月分割线）、分页加载、刷新同步                                                     |

## 3. 状态与数据流

```text
用户点击
  → stores/indexFilter 更新（mode / types / statuses / dateRange / sortMode）
  → watch 写入 localStorage（VIDEO_INFO 存储封装，persist=true）
  → query.signature 变化
  → IndexList.reload()：页码归 1、请求版本 +1、清空列表
  → data/series.querySeries()：applySeriesQuery(全量) → paginateSeries(第一页)
  → 版本号匹配才写入 datas，segments 重新计算并渲染分割线
```

要点：

- **签名驱动**：`IndexList` 只监听 `filter.signature`（查询条件的 JSON 字符串），不逐个监听字段，避免同一轮里多次刷新。
- **版本号丢弃过期响应**：搜索词与过滤条件都可能连续变化，`requestVersion` 保证只有最后一次请求能落表。
- **刷新事件重算**：全量刷新给出的列表未经过滤，`IndexList` 用 `applySeriesQuery()` 按当前条件重算后再截取已加载页数。
- **时间轴独立取数**：`IndexFilterDate` 用 `Series.getAllSeries()` 构建刻度，刻度覆盖全部系列，不受标签/状态过滤影响；否则选中标签后时间轴会缺少年份。

## 4. 关键约束

- 网格列表中的分割线必须 `grid-column: 1 / -1`，否则会被压进单列。
- 过滤栏高度固定（`--filter-bar-height: 62px`，为两个分段控件上方的标签文案留出空间）且 `position: sticky; bottom` 贴住滚动容器底部；时间轴与标签的展开态都向上浮动并盖住列表，不能让列表区域发生位移。
- 时间轴内联在过滤栏内容区：收起态是 26px 高的白色波形概览，展开态是 112px 的完整面板。宿主 `.axis-wrap` 高度固定为 26px，展开的面板是它的子元素并向上溢出；指针悬浮在溢出部分仍算作宿主子树内部，因此不会出现「展开→指针离开→收起」的抖动。面板与标签悬浮层都使用不透明深色底（`d-8`），避免透出封面影响刻度判读。
- 收起态配色跟随过滤栏（`sidebar-bg` 是浅紫半透明），柱体一律用白色半透明、选中月份纯白，轴底只留一条 `rgba(#fff, 0.2)` 基线；不要用 `d-*` 深色柱体或深色选区蒙层，深色在浅紫上会被看成脏黑条纹。柱高收起态 2 - 18px、展开态 3 - 40px，空档月份只保留 2px 短刻度维持节奏。
- 时间轴不使用原生横向滚动，而是维护一个**可见窗口** `AxisWindow { start, count }`：只渲染窗口内的月份并用 flex 等比铺满可视区。窗口越小单月刻度越宽（放大），窗口越大刻度越窄（缩小总范围）；刻度宽度由 `可视区宽度 / count` 现算，不再依赖 `--tick-width` 常量。
- 滚轮缩放以鼠标位置为锚点（`zoomAxisWindow`），放大上限是 `AXIS_MIN_VISIBLE_MONTHS`（6 个月），缩小上限是全部月份；`Shift + 滚轮`/触控板横向滑动平移窗口（`panAxisWindow`），两者都收敛在数据范围内。面板顶部「显示全部」可一键还原。
- 拖动使用 `setPointerCapture` + `pointerdown.preventDefault()`，并监听 window 的 `pointermove/up/cancel`；拖到可视区左右外侧时按帧自动平移窗口，因此可以连续划选超出当前视野的区间。拖动过程只更新本地预览，松手才提交；按下与松开落在同一刻度即选中单月。
- 当前时间位置必须能被直接看到：展开时面板顶部显示选中范围与当前可见窗口；收起时范围文案贴着选区块浮在轴上方（拖动时跟随预览范围），定位由 `bandTipStyle()` 给出——选区中心超过 `BAND_TIP_RIGHT_THRESHOLD`（68%）时改为与选区右端右对齐，文字始终朝容器内部延伸。轴上用半透明白色块 + 不透明白色左右描边标出范围。
- 时间轴必须铺满过滤栏内容区的剩余宽度，右侧不留空白占位。原来的做法是给「全部时间」文案预留 86px 且选中后把文案设为透明，结果轴右端出现一大块没有刻度的空档；现在改成固定 52px 的操作位（`.actions`），未筛选时放「全部时间」文字、筛选后换成「清除」文字按钮，两种状态宽度一致，轴不会被重新分格，也不会有空档。
- 清除按钮用文字而不是图标，配色走中性白描边 + 主题亮色文字（`l-9`）与 `rgba(#fff, …)` 背景，hover 时提高白色透明度、`:active` 压暗，五套主题下都不用单独改；不要用 `el-button` 的 text 类型再叠一堆变量覆盖。
- 分割线（`IndexList.vue` 的 `.divider`）是深色背景上的提示层：细线与两侧文字都必须**亮于背景**，当前取 `l-5`（线、数量）与 `l-6`（月份标题）。不要用 `d-*` 深色梯度，那会比背景更暗、几乎看不见。
- 标签组超过一行时，收起态用「允许换行 + `max-height` 一行 + `overflow: hidden`」裁切，用 `scrollHeight > clientHeight` 判断是否可展开；展开态改成绝对定位并铺满内容区宽度，同样向上浮出不推挤列表。
- 时间范围用 `YYYY-MM` 字符串保存，字符串比较等价于时间比较；指定范围时未设置上线时间的条目一律排除。
- 排序默认 `date`：月份倒序、同月按拼音名称升序（与数据层初始化使用同一套 `Intl.Collator` 配置）、无上线时间排最后。
- 本地存储读取必须逐项校验（方式白名单、数字数组、范围格式），脏数据回退默认值，不能让旧版本残留结构导致列表空白。

## 5. 扩展点与已知限制

- 新增过滤维度：在 `SeriesFilterMode` 增加枚举、在 `SeriesQuery` 增加字段、在 `applySeriesQuery()` 加一条判定，再在 `IndexFilterBar` 挂一个新组件；不要在组件里直接过滤 `datas`。
- 新增排序方式：扩展 `SeriesSortMode` 并在 `sortSeriesList()` 加分支；`IndexList` 的 `segments` 只在 `date` 模式下插分割线。
- 已知限制：列表按 `title` 排序但卡片显示目录名 `name`，两者不一致时顺序与文字观感可能不同（沿用改造前的既有行为）；时间轴刻度按月份连续补齐，跨度过大时通过缩放查看，不再依赖横向滚动。

## 6. 验证方式

- 单元测试：`pnpm exec vitest run`（`test/web/series-query.test.ts`、`test/web/time-axis.test.ts`）覆盖过滤组合、排序边界、分组、刻度补齐、窗口收敛、缩放锚点、平移边界、范围色块裁剪与坐标换算。
- 手工验证：
    1. 首页默认按上线时间倒序，每个月有分割线且标注数量；
    2. 切换「标签」多选后列表数量与分割线同步变化，刷新页面后选择仍在；
    3. 切换「状态」验证与标签为「与」关系；
    4. 「时间」悬浮展开面板，拖动划选区间：拖动过程中色块实时跟随、面板顶部显示预览范围，松手后收起，范围文案贴在选区块上方且列表只剩范围内条目；选区贴右端时文案改为右对齐不溢出；清除后恢复为右侧「全部时间」；
    5. 收起态波形为白色半透明柱体，选中区间是白色薄蒙层 + 白色两端描边，不应出现黑色条纹；切换选中状态时轴宽不变、刻度不跳动；轴右端紧贴操作位，不能出现没有刻度的空档；
    6. 筛选后右侧出现「清除」文字按钮，点击后恢复「全部时间」，两种状态下轴宽相同；
    7. 面板内滚轮缩放：刻度数量变化、锚点附近月份不跳动；`Shift + 滚轮` 平移；「显示全部」还原；收起横栏仍能看到同一段范围和缩放后的位置；
    8. 缩放到只剩少量月份后按住拖到面板右外侧，窗口持续右移并能连续划选更晚的区间；
    9. 滚动列表时过滤栏始终贴底，不遮挡最后一行卡片。
